# Commit messages

Use Conventional Commits compatible with `@commitlint/config-conventional`:
`type(scope): subject`. The scope is optional. Use a lowercase type and subject,
no final period, and keep the header within 100 characters. Choose the type
that describes the change, such as `feat`, `fix`, `docs`, `style`, `refactor`,
`perf`, `test`, `build`, `ci`, or `chore`.
